# Romero Finanças

A local personal finance management application built with Python, Flet, and SQLite.

Romero Finanças was developed to help users organize and manage their personal finances through a simple, practical, and accessible interface.

## About the Project

Romero Finanças is a personal finance application designed to bring different financial management features together in one place.

The application uses a local SQLite database to store information on the device, without requiring a permanent internet connection or an online account.

## Features

- **Financial Management:** Organize personal financial records.
- **Expenses:** Register and manage expenses.
- **Investments:** View and organize investment information.
- **Market Comparison:** Compare product prices across different markets.
- **Local Data Storage:** Store application data using SQLite.
